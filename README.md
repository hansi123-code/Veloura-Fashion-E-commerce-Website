Veloura – Fashion E-commerce Website

Veloura is a modern and elegant fashion e-commerce website developed using React and Vite. It showcases a stylish shopping experience with carefully designed sections for exploring fashion collections and products.

Features-

-Elegant and modern homepage

-Hero section with Explore navigation

-New Arrivals section

-Shop by Category

-Category-based product browsing

-Promotional banner

-Navigation between website sections

Technologies Used-

-React.js

-JavaScript

-HTML5

-CSS3

-Vite
